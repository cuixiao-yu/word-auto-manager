## 灵感
本人在使用**不背单词** App 时，发现不背单词的生词本导出功能**居然需要付费**？？

我无疑是愤怒的。

这十分地不划算，况且软件自带的导出效果并不是我想要的，因此萌生了开发一个自动采集并导出单词本的工具。

## 优化方向
由于出于自用而进行开发，该工具存在以下局限性：

- 该工具读取固定窗口名，目前只支持 vivo 手机通过办公套件连接电脑投屏后使用
- 该工具是在 Windows 平台下开发的，目前暂无跨平台的支持
- 目前只针对了不背单词的页面进行了识别，故其他的单词软件并不适用
- 使用上局限于命令行，未来考虑打包为图形化可执行文件
